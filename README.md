# Spotify Song Bot 🎵

ربات تلگرام: لینک آهنگ بده (اسپاتیفای، اپل موزیک، دیزر، ساندکلاد، یوتیوب) یا فقط اسم آهنگ رو بنویس — mp3 تگ‌دار با کاور اصلی بگیر.

## امکانات

- لینک **تک‌آهنگ**، **آلبوم** و **پلی‌لیست** اسپاتیفای → دانلود mp3
- لینک **اپل موزیک**، **دیزر**، **ساندکلاد**، **یوتیوب**
- **چند لینک یکجا**: چند تا لینک (حتی قاطی از سرویس‌های مختلف) رو توی یه پیام بفرست
- **سرچ با اسم**: بدون لینک، فقط اسم آهنگ رو بنویس
- **انتخاب کیفیت**: 128 / 192 / 320kbps (دکمه‌ای)
- **کیفیت پیش‌فرض شخصی**: با `/settings` یه بار ست کن
- **پیشرفت دانلود**: وضعیت لحظه‌ای
- **صف دانلود**: چند آهنگ پشت سر هم قاطی نمی‌کنن
- **اطلاعات کامل**: اسم آلبوم، سال انتشار، مدت‌زمان، شماره ترک توی کپشن
- **نسخه تند ⚡ / کند 🐌** (nightcore/slowed) با دکمه زیر هر آهنگ
- **آهنگ‌های مشابه 🎧**: لیست دکمه‌ای پیشنهاد
- **متن آهنگ 📝** + **ترجمه فارسی 🌐** + **فایل LRC 📄** (متن همگام‌شده)
- **حالت اینلاین**: توی هر چتی `@username_bot اسم آهنگ` رو سرچ کن
  (اول توی BotFather با `/setinline` اینلاین رو فعال کن)
- **آمار مدیر**: `/stats` (فقط با `ADMIN_ID`)
- **آمار شخصی**: `/mystats`

## Deploy

1. توی [Railway](https://railway.app) پروژه جدید → **Deploy from GitHub repo**
2. متغیر محیطی `ADMIN_ID` = آیدی عددی تلگرام خودت (برای `/stats`)
3. (اختیاری) اگه اینلاین می‌خوای، توی BotFather `/setinline` رو فعال کن

توکن بات توی `bot.py` هاردکد شده؛ با `BOT_TOKEN=xxx` می‌تونی اورراید کنی.
دیتای تنظیمات/آمار توی `DATA_DIR` (پیش‌فرض `/tmp/spotibot_data`) ذخیره می‌شه —
برای ماندگاری، یه Volume به اون مسیر وصل کن.

## لوکال

```bash
pip install -r requirements.txt
ADMIN_ID=123456789 python3 bot.py
```
