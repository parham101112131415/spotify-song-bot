# Spotify Song Bot 🎵

ربات تلگرام: لینک آهنگ اسپاتیفای (track) بده، mp3 تگ‌دار با کاور اصلی بگیر.

## امکانات

- لینک تک‌آهنگ اسپاتیفای (`open.spotify.com/track/...`) → دانلود mp3
- تگ خودکار: اسم آهنگ + خواننده + کاور اصلی
- دکمه **متن آهنگ 📝** زیر پیام: با زدنش متن آهنگ فرستاده میشه

## Deploy روی Railway

1. توی [Railway](https://railway.app) یه پروژه جدید بساز.
2. **Deploy from GitHub repo** → همین ریپو رو انتخاب کن.
3. دیپلوی کن — تمام. توکن بات توی خود کد هست، هیچ متغیری لازم نیست.
4. توی تلگرام برو سراغ بات، `/start` بزن و لینک آهنگ بفرست.

## لوکال

```bash
pip install -r requirements.txt
python3 bot.py
```

## نکته

- توکن بات داخل `bot.py` هاردکد شده (خط `BOT_TOKEN`) تا بدون تنظیمات بالا بیاد.
  اگه خواستی عوضش کنی، یا همون خط رو ویرایش کن یا موقع اجرا `BOT_TOKEN=xxx python3 bot.py` بده.
- فقط لینک **تک‌آهنگ** (`/track/`) ساپورت میشه.
- برای تشخیص آهنگ از YouTube از `yt-dlp` و ffmpeg (باندل‌شده در Docker) استفاده میشه.
